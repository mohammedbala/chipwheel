    01 / Set up

    How to read the bench

    START is edge 0. Each instruction takes one enabled clock. WAIT N then stalls N clocks. SHIFT puts the low data bit on the pin. DJNZ repeats the loop.

    The diagram shows state after the selected edge. Program loading is assumed complete. This teaching model does not run RTL or validate physical timing.
